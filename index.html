01 Field notes

About

Since 2012 I’ve been taking systems from on‑prem to cloud‑native, from slow to fast, from fragile to boring — and now AI from demo to dependable. I own the architecture, write the code, and stay for production.

I’m an AI and cloud architect based in Kathmandu. Most of my work lives where enterprise meets scale: LLM applications and agents on top of .NET microservices and secure APIs, React and Angular front‑ends, and AWS infrastructure defined in Terraform.

For more than seven years I’ve worked on Monotype’s font ecosystem — Fonts.com, MyFonts, Linotype, FontShop — alongside Fontworks and Fontplus in Japan. I’ve also owned microservices and AWS delivery for HP’s Workforce Experience Platform, and led workflow services for the State of Colorado’s unemployment insurance system with Deloitte.

More and more of my work is AI: LLM applications and retrieval over company data, multi‑agent systems with review gates and persistent memory, and cloud AI services wired into platforms that already have to be secure, observable and fast.

Flagship R&D · multi‑agent system

An organization run by agents

Role‑separated agents on Claude Code — a CEO, Strategist, Researcher, Builder and Reviewer, plus Growth, Comms, Legal and Investor. Every factual claim needs a cited source, the Reviewer can block any plan, memory lives in files and git so each decision is auditable, and scheduled cloud runs keep the organization working between sessions. One governance cycle took an idea from proposal to a live, shipped website in about four hours.

  1. Strategist proposes three bets
  2. Reviewer blocks an unverified claim
  3. Researcher verifies at the primary source
  4. Reviewer lifts the block
  5. Builder ships the site
